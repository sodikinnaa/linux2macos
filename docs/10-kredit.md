# 10. Kredit & Lisensi

linux2macos hanya berisi script dan dokumentasi. Semua tema, ikon, font, dan ekstensi **diunduh langsung dari sumber aslinya** saat instalasi dan tidak disimpan di repo ini.

| Proyek | Pembuat | Lisensi | Dipakai untuk |
|---|---|---|---|
| [WhiteSur-gtk-theme](https://github.com/vinceliuice/WhiteSur-gtk-theme) | Vince Liuice | MIT | Tema GTK & GNOME Shell, logo Apple untuk menu, tema GDM |
| [WhiteSur-icon-theme](https://github.com/vinceliuice/WhiteSur-icon-theme) | Vince Liuice | GPL-3.0 | Ikon |
| [WhiteSur-cursors](https://github.com/vinceliuice/WhiteSur-cursors) | Vince Liuice | GPL-3.0 | Kursor |
| [WhiteSur-wallpapers](https://github.com/vinceliuice/WhiteSur-wallpapers) | Vince Liuice | MIT | Wallpaper |
| [Inter](https://github.com/rsms/inter) | Rasmus Andersson | SIL OFL 1.1 | Font antarmuka |
| [Nerd Fonts – JetBrainsMono](https://github.com/ryanoasis/nerd-fonts) | Ryan L McIntyre / JetBrains | SIL OFL 1.1 / MIT | Font terminal |
| [Starship](https://github.com/starship/starship) | Starship contributors | ISC | Prompt terminal |
| [fastfetch](https://github.com/fastfetch-cli/fastfetch) | fastfetch contributors | MIT | Info sistem |
| [User Themes](https://extensions.gnome.org/extension/19/user-themes/) | GNOME | GPL-2.0+ | Tema GNOME Shell |

Lisensi masing‑masing proyek bisa berubah. Cek repo aslinya untuk versi terbaru.
